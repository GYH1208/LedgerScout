# Web 真实查询接入

用户要求保留现有 UI，开始真实测试。实现本地 Node HTTP 适配器接入已有 runAgent；浏览器使用同源 /api，经 Vite 代理到 127.0.0.1:4174。真实页面使用 `?mode=live`，演示页面保持独立；真实模式不加载任何样例会话或金额，不因失败回退演示。

服务端逐次读取本地配置，密钥仅在服务端使用。全局单个在途运行，沿用现有 Runtime 默认预算、工具、证据保存、取消 signal、resumable 和显式恢复校验。前端轮询当前本地服务的会话状态；会话视图在本地服务重启后重置，底层运行证据仍在 runtime-results 持久保存，首轮不新增持久化 Web 索引。

API 仅监听回环，验证 Host/Origin，变更请求必须具备 JSON Content-Type 与自定义客户端头。请求体、问题长度、可访问会话/运行/查询和分页大小受限。浏览器只能通过已注册的运行和 queryId 取得投影后的归一化证据，不允许任意磁盘路径或远程 URL。保留完整整数、币种与部分数据提示，直接显示 Runtime 生成的事实文本并链接对应 queryId。

验收：离线覆盖缺配置、不受支持的请求、请求来源与体积、并发、取消、恢复、查询归属、脱敏和分页；随后用真实已配置 DeepSeek/Alchemy/Etherscan，经页面完成 ENS余额、最近七天资金流、证据展开和追问。取消与恢复先离线验证，真实调用保持有界。不部署、不改系统代理，不改变底层金额算法。
