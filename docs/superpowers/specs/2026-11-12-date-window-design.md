# 日期窗口查询设计

## 用户选择与目标

用户选择 Etherscan 时间转区块接口，最近七天表示查询时刻向前 168 小时，日历日期默认北京时间。Windows 编码器安装本轮延期。
让交易和双向转账按真实时间窗口查询，结果展示原始时间及实际区块范围；分页上限仍为 partial。

## 方案

用户已选择复用 Etherscan `getblocknobytime`，通常每个窗口两次映射请求。Alchemy 二分查找需要较多 HTTP 请求，在现有32次尝试限制下不采用。
使用 Alchemy `eth_getBlockByNumber` 读取映射边界及相邻区块的时间，校验 Etherscan 的结果覆盖所需时间，防止时区或边界误差。
所有请求走原 Transport，计入同一预算、取消、超时、脱敏和原始证据保存。
来源：https://docs.etherscan.io/api-reference/endpoint/getblocknobytime 及 https://www.alchemy.com/docs/chains/ethereum/ethereum-api-endpoints/eth-get-block-by-number 。

## 首次支持的输入

- 滚动窗口：最近/过去/近 N 小时、N 天、N 周；英文 last/past N hours/days/weeks；中文数字支持一到九十九。以本轮创建时刻为基准。
- 日历窗口：今天、昨天、前天、本周、上周、本月、上月；北京时间，周一为周起点。当前周期截至本轮创建时刻。
- 绝对日期：YYYY-MM-DD、YYYY/MM/DD、YYYY年M月D日；单日或两个日期的起止区间。末日完整包含，未来部分截到本轮时刻并明确提示。
- 无法确定的日期表达、无效日期、开始晚于结束、窗口完全在未来、日期与显式区块同时出现：澄清，不调用模型或数据接口。
- 日期窗口只应用于普通交易与转账。余额仍为固定区块余额，不承诺时间范围内余额变化；混合请求中历史工具受窗口约束。

## 时间与区块规则

时间以整数秒保存，窗口为含首尾秒的 [startTimestamp, endTimestamp]，附 Asia/Shanghai 时区和本轮基准时刻。最近 N 天相差 N×86400 秒。
Etherscan before(startTimestamp−1) + 1 为候选起始区块，before(endTimestamp) 为候选结束区块。区块限定在本轮已验证主网快照以内。
用 Alchemy 真实区块头验证：起始时间不早于 start；前一区块早于 start；结束时间不晚于 end；若结束早于快照，则后一区块晚于 end。相同区块复用校验请求。
日期早于主网上线、映射服务失败、不满足上述边界：明确失败，保留证据，不扩大范围、不退回全历史。没有已出块的窗口返回明确说明，不伪装成完整历史。

## 接入与恢复

增加独立确定性日期解析模块；模型不能决定时区、当前时间或把日期自行换成区块。
运行初始解析并把窗口保存在 checkpoint；显式恢复读取原窗口，不重新计算“最近七天”。旧检查点未带窗口时保持原行为。
QueryService 接收本轮窗口，只在第一个历史工具内部解析一次区块边界；本轮其他历史查询复用内存缓存。
时间窗口下由程序强制写入查询 startBlock/endBlock，模型提供冲突范围时拒绝。不同地址的历史查询共享已验证窗口。
QueryResult.range 增加可选 timeWindow 元数据（目标时间、时区、基准时刻、快照、映射区块及边界区块头校验值）。只有通过校验的映射才能附加到查询。原始映射请求保存在该查询证据；复用者附 sourceQueryId 指向首个来源。
检查点只保存原始时间窗口，完成查询仍使用现有 queryRefs 的 query.json 哈希验证。恢复时从同一恢复链且哈希已验证的查询中恢复对应映射缓存；验证时间、区块和快照一致。源查询保留在证据集合，复用者不得伪造来源。
若进程在查询结果写盘或检查点引用保存之前退出，则不声称已有可恢复的映射证据；恢复会按原时间窗口、原快照重新映射，HTTP尝试继续累计。这与中断查询从第一页重试一致。
独立设计检查指出原先“先引用尚未保存的query.json”方案存在持久化缺口，故采用上述查询边界提交方案，避免引入额外映射事务；代价是中途退出可能重做只读映射。
回答模板显示目标时间、实际区块范围、是否截至查询时刻及完整性。

## 验收

确定性测试覆盖北京时间跨日、闰年、无效日期、滚动窗口、自然周/月、未来截断、冲突范围和不支持表达。
真实 Transport 模拟 HTTP 测试覆盖映射成功、边界恰好相等、相邻区块校验、供应商失败、异常返回、预算耗尽和取消。
Pi 集成验证真实工具约束、部分历史、恢复不漂移窗口、不重复映射与完整旧测试兼容。
最后用公开测试地址进行真实“最近七天”查询，核对边界证据，记录用量与 partial 状态；不升级套餐或安装依赖。
