# LedgerScout 首版 Web UI 设计

## 目标与已选方向

用户选择第三轮消息中展示的第 2 张草图：对话研究室。视觉依据为 [选定草图](../../design/selected-conversation-ui.png)，包含首页与分析结果两种状态。参考苹果官网的留白、字体层级和白灰蓝配色。

目标：让用户输入地址或 ENS 与问题，通过对话阅读资金流结果、展开证据、继续追问。用户已确认先交付可点击的本地前端原型，演示完整交互，再单独接入真实 Runtime。

## 方案比较

- 第 1 版：居中提问入口与独立结果阅读页，入口突出，但多轮研究上下文较弱。
- 第 2 版（用户已选）：左侧会话、中间对话、右侧证据，适合持续研究，展开证据时需控制正文宽度。
- 第 3 版：报告阅读布局，单次结论清楚，但历史会话切换与追问较次要。

## 页面与布局

- 桌面基准为 1440 × 1024。左侧约 220px，浅灰背景；放置文字品牌、Ethereum Mainnet 只读说明、新建研究与近期会话。
- 首页正文居中，大标题“看清链上资金的来龙去脉。”，副标题“从一个地址、一个问题开始。”；输入框与蓝色“开始研究”按钮为主操作。
- 结果状态在中间按对话顺序显示问题、结论、ETH 流入/流出/净流量和往来明细。追问输入区位于底部；滚动内容不可被其遮住。
- 右侧约 280px 的证据面板默认关闭，点击引用或“查看证据”展开；关闭后释放正文宽度。面板展示引用对应的查询对象、范围、完整性与来源记录。
- 布局比例按实际容器调整。窄屏隐藏会话侧栏，使用菜单抽屉；证据使用覆盖面板，表格在自身区域横向滚动，避免整页溢出。这些响应式细节为实现建议。

## 视觉规则

白色主背景、#f5f5f7 侧栏、#1d1d1f 正文、#6e6e73 次要文字、#0071e3 主操作。使用系统 sans-serif 与中文苹方回退；正文 14–16px，大标题仅用于首页。分组优先留白与细分隔线。图标使用现成库；不生成新的品牌标志，不使用装饰性大图。金额使用等宽数字。

## 核心交互

1. 点击示例填充输入框；输入非空问题后提交，空白输入不可提交。
2. 提交显示查询进度和取消按钮，阻止重复提交；结果出现后允许追问。
3. 新建研究返回空白首页；会话列表切换对应对话，保留当前页内的演示会话状态。
4. 点击引用打开其对应证据；复制地址复制完整值并显示成功或失败提示。
5. 原型展示 loading、completed、partial、awaiting_user、failed、cancelled、exhausted 状态。失败时说明原因，恢复仅在 resumable 为真时可用，不自动恢复。
6. 键盘可操作全部主要控件，焦点清楚；抽屉支持 Escape 关闭并恢复焦点，进度变化可被辅助技术读取。

## 数据语义与限制

原型数据全程标记“演示数据 · 非实时查询”，日期使用固定演示锚点 2026-11-14，时间采用 Asia/Shanghai；不得把演示提交描述为已完成真实链上查询。测试脚本或场景入口可切换终态，不根据任意问题伪造研究结论。

示例 ETH 流入 1.24、流出 0.86、净流入 0.38；不跨币种累计。部分结果始终展示“仅覆盖已取得记录，不代表完整历史”，结论也限定为已取得样本。示例中的单笔往来不能冒充全部聚合记录。证据面板应明确标注其为演示来源。

ENS 绑定标记为当前快照，不声称是历史日期的绑定。普通交易与转账不混算；不推断往来地址身份、不输出利润或法币估值。不实现交易、钱包连接、多链或自动恢复。

## 真实接入边界

现有 `packages/agent-runtime/src/runtime.ts` 提供 `runAgent`、`onEvent`、取消 signal 与 `RunResult`，包括状态、查询、ENS 证明及 resumable。真实接入需单独增加本地服务适配层，会话索引和证据读取接口尚不存在，不能把这些当作已经可用的 HTTP API。密钥与任意磁盘路径不可进入浏览器。先原型后接入的顺序待确认，本文不授权新增外部 API 调用或部署。

## 验收与实现者可决定事项

先在 1440 × 1024 分别比对首页和结果状态，再验证提交、取消、会话切换、追问、引用定位、复制、异常状态及窄屏抽屉。通过浏览器交互验证和参考图并排对照后才能称为可用原型。字体回退、具体间距、图标库和前端模板由实现者按视觉一致性选择；不要求修改现有链上算法。
