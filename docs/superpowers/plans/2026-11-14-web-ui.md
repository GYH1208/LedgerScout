# Web UI Prototype Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build the approved conversation UI as a usable local demo.

**Architecture:** A self-contained React/Vite app in `apps/research-prototype`. In-memory demonstration sessions and a bounded simulated run supply the view; no provider or runtime calls. The selected image is the visual truth.

**Tech Stack:** React 19, Vite, system fonts, a standard icon library, Playwright for browser verification.

**Spec:** `docs/superpowers/specs/2026-11-14-web-ui-design.md`

## Global Constraints

- White/#f5f5f7/#0071e3 visual system; desktop baseline 1440 × 1024.
- All research data is labelled 演示数据 · 非实时查询.
- No secrets, API calls, deployment, real wallet actions, or durable session persistence.
- Partial conclusions cover acquired records only; no currency aggregation or identity inference.

## Review Focus

- Cancelling or changing conversations cannot deliver a stale simulated result to a different thread.
- Arbitrary questions must not receive invented research facts; unrecognised demo inputs clarify.
- Multiple citations must open their own evidence, with truthful demo labels.
- Mobile drawers must trap focus and restore it on close; inputs cannot be obscured.
- A failed or nonresumable state must never silently resume.
