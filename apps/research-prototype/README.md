# LedgerScout 对话研究原型

基于选定的第 2 版视觉草图：左侧会话、中间研究对话、右侧证据。采用白灰蓝配色与系统字体。

## 运行

使用 Node.js >=22.19.0，在本目录运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

浏览器打开 `http://127.0.0.1:4173/`。这是独立前端目录，根目录的 npm ci 不会安装本目录依赖。

## 可点选的流程

- 首页示例填入问题，提交后展示加载、结果与追问。
- 切换历史会话、新建研究、取消和显式恢复。
- 引用 [1]、[2] 对应不同的证据，支持复制完整地址。
- 侧栏“演示场景”控制下一次演示的状态；预算耗尽不可恢复。
- 手机使用会话抽屉和证据抽屉，支持键盘焦点约束与 Escape 关闭。

## 演示边界

所有数值与证据都是界面样例，使用固定日期锚点 2026-11-14、Asia/Shanghai。支持首页展示的 vitalik.eth 最近七天资金流、当前 ETH 余额，以及结果中的来源追问示例；其他目标或范围进入澄清，不执行自然语言研究。明细两笔不是资金汇总的全部记录。

默认演示模式不调用 DeepSeek、Alchemy 或 Etherscan，不读取密钥。演示会话仅保存在内存，刷新页面即重置；演示恢复不代表真实检查点恢复。本项目没有部署。

## 真实查询模式

在仓库根目录 `.env` 配置三项已有服务密钥（参照根目录 `.env.example`），随后在根目录执行 `npm run ui:live`，打开 `http://127.0.0.1:4173/?mode=live`。不要将密钥放入前端 `VITE_*` 变量或发到聊天。缺配置时页面禁止提交并自动重新检查；新增密钥无需重启服务。

本地 API 只监听 `127.0.0.1:4174`，页面通过同源代理访问。使用现有 Runtime 的预算、证据保存、取消和显式恢复；不会因失败切回样例。Web 会话、消息和任务索引存于根目录 `runtime-results/web.sqlite`，重启后仍可读取、打开证据和继续追问；底层证据与检查点仍在 `runtime-results/<sessionId>/<runId>/` 保存。当前最多一个真实查询同时执行。

首次启动会导入本机结构有效的旧终态记录，畸形条目会跳过并提示。启动、刷新、读取旧记录不请求供应商。强制中断的任务会在重启后显示“查询已中断”；检查点和证据通过原 Runtime 校验后可点击恢复，沿用累计预算和原查询范围。没有检查点时可重新提交问题，不会后台自动重试。

页面目前显示最近 30 个会话、每个会话最近 20 轮，超出时有提示，数据库不删除旧记录。备份需停止服务后整体复制 `runtime-results/`，确保 SQLite 数据库与原始证据一起保存。数据库损坏、不可写或被其他实例占用时，页面明确报错并保留原数据。

现有 HTTP(S) 代理环境变量仅传给本地服务子进程，并启用 Node 环境代理支持，不修改系统代理。使用固定端口 4173/4174，变更来源端口需要同步调整服务端来源校验。

`npm run test:live-offline` 使用隔离浏览器内的离线传输测试真实模式 UI，不请求供应商。`npm run test:live` **会调用真实模型和数据服务并产生用量**，依次验收 ENS 余额、最近七天资金流、证据和不刷新的追问；配置缺失时在首次供应商调用前停止。实际验收记录与截图保存在根目录忽略的 `runtime-results/web-live_*/`，不会混入离线测试结果。

`npm run test:persistence` 使用临时目录内的真实本地 HTTP、SQLite 和 Pi Runtime，仅将上游模型/链数据响应替换为离线数据；通过浏览器验证进程重启、精确证据、旧证据追问、SIGKILL 中断、手动恢复和手机证据抽屉，不调用真实供应商。结果与截图命名为 `docs/design/qa/sqlite-*`。

## 验证

```sh
npm run build
npm test
# 保持 dev server 运行，使用本机安装的 Google Chrome：
npm run test:ui
```

`PROTOTYPE_URL` 可覆盖浏览器检查的目标地址。截图和结果保存在仓库 `docs/design/qa/`。系统剪贴板权限在无头浏览器的隔离会话中授权，不修改用户浏览器配置。

打包保留模板自带的静态站点结构；`test:sites` 仅测试打包契约，不发布站点。视觉对照与限制见 [design-qa.md](design-qa.md)。
